Descripcion del Sistema

El Sistema de Gestión de Clientes es una aplicación web simple desarrollada en PHP que permite administrar la información de contacto de los clientes de un negocio de forma rápida y organizada.

Sirve para registrar nuevos clientes, consultar los datos existentes, editar información cuando cambia (como un teléfono o dirección) y eliminar registros que ya no sean necesarios. Todo desde una interfaz visual clara, sin necesidad de conocimientos técnicos avanzados.

Es ideal para pequeños comercios, emprendimientos o profesionales independientes que necesitan llevar un control básico de su cartera de clientes sin complicaciones, ya que funciona de inmediato sin configuraciones complejas de base de datos.
